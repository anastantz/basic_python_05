# Python Basics: Predecessor and Successor | Python Básico: Antecessor e Sucessor

This repository contains the fifth practical exercise from the Programming Language Paradigms course (Digital Games Degree). The goal is to demonstrate the use of basic mathematical operators (addition and subtraction) in Python using a simple procedural approach.

Este repositório contém o quinto exercício prático da disciplina de Paradigmas de Linguagem de Programação (curso de Jogos Digitais). O objetivo é demonstrar o uso de operadores matemáticos básicos (adição e subtração) em Python usando uma abordagem procedural simples.

## 💻 About the Project | Sobre o Projeto

The script executes sequentially, prompting the user for an integer via the terminal. It then uses subtraction and addition operators to calculate the number's predecessor and successor, returning a formatted string with the results using `f-strings`. It was developed in two versions (English and Brazilian Portuguese).

O script é executado de forma sequencial, pedindo ao usuário um número inteiro via terminal. Em seguida, utiliza operadores de subtração e adição para calcular o antecessor e o sucessor do número, retornando uma string formatada com os resultados usando `f-strings`. Foi desenvolvido em duas versões (Inglês e Português Brasileiro).
